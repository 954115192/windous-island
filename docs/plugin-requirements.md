# 插件视觉与布局要求

## 目标

插件内容应当像直接绘制在灵动岛内部，而不是一个嵌在灵动岛中的独立卡片。Host 的小岛边界是唯一的外轮廓。

## 必须遵守

- 插件可以不设置底色：小岛的黑色底由 Host 绘制，插件页面保持透明即可。插件自带底色也可以，但底色必须铺满整个页面（Host 会按小岛外轮廓裁掉溢出部分）。
- Medium / Large 根容器不得绘制外层边框。
- Medium / Large 根容器不得绘制外层阴影、渐变卡片背景或第二层圆角卡片。
- 不要为插件根容器添加独立的外边距，以免露出小岛下方的直角或背景缝隙。
- Small 多插件只负责自己的内容，插件之间的分隔由 Host 统一绘制。
- 插件内容不要在 Host hover 时自行缩放、位移或重新布局。插件应直接以目标尺寸呈现，由 Host 的外部小岛边界负责动画和裁剪。
- 插件内容超出根容器时必须使用 `overflow: hidden`；不要让阴影、伪元素或绝对定位内容穿出根容器。

## 推荐基础样式

```css
html, body, #app {
  width: 100%;
  height: 100%;
  margin: 0;
  overflow: hidden;
  background: transparent;
}

.medium, .large {
  width: 100%;
  height: 100%;
  overflow: hidden;
  background: transparent;
  border: 0;
  border-radius: 0;
  box-shadow: none;
}
```

插件可以在内部使用自己的按钮、图表、图片和装饰，但这些装饰不能代替 Host 的小岛外轮廓。

## Host 行为

Host 会保持插件的目标布局尺寸，并用灵动岛外轮廓的圆角裁剪每个插件页面。

裁剪是按插件 View 逐个施加的：Electron 中父 View 的 `setBorderRadius` 只裁剪父 View 自己的绘制，不会裁剪作为子视图的 `WebContentsView`，因此 Host 把圆角半径同时下发到每个插件 View 上（插件 View 自身的圆角才会真正裁掉页面画出来的方角）。半径按插件相对小岛边缘的内缩量递减，即 `插件圆角 = 小岛实际圆角 - 插件内缩量`：只有贴到小岛左右两端的插件会被倒角，完全位于小岛内部的插件保持直角。例如 38px 高的小岛声明 `border-radius: 28px` 时浏览器实际把半径压到 19px（不能超过短边的一半），左端插件内缩 8px，于是该插件的裁剪圆角是 11px。Electron 只提供四角统一的半径，所以贴边的插件四角会被一起倒角；插件保持透明或纯黑时这一点不可见。

因为插件 View 在动画期间始终保持目标尺寸（只有小岛外壳在弹性变化），带不透明底色的插件在展开/收起的动画过程中仍可能露出直角。把小岛底色交给 Host、插件页面保持透明就不会出现这个问题。

小岛被缩放到很小（`miniScale` 调低后插件 View 的短边不足 32px）时 Electron 会跳过原生圆角裁剪，此时同样靠"插件透明 + Host 画底"保证外形正确。

## 宿主视觉 token（取色只走变量，不要写死 hex）

宿主有一套唯一的 token 源：`console-apps/theme.css`（岛壳、控制台、工作台共用）。
插件拿不到那个文件，宿主在 hello / theme 里把同一套值注入进来 —— 插件按下面的变量取色，
就不会出现"插件和岛壳对不上色"，宿主换主题时插件也不用改。

| 注入的 CSS 变量 | 对应 theme 字段 | 值 | 用在哪 |
| --- | --- | --- | --- |
| `--island-surface` | `theme.surface` | `#000000` | 岛体底色（通常不需要插件自己画） |
| `--island-ink` | `theme.ink` | `#F4F4F5` | 主数值、标题 |
| `--island-ink-dim` | `theme.inkDim` | `#A1A1AA` | 标签、单位、次要说明 |
| `--island-accent` | `theme.accent` | `#3B82F6` | 状态点、主操作、选中态。**一屏只承载一个「当前事实」** |
| `--island-radius` | `theme.radius` | 实际生效值（被短边夹住） | 插件内部卡片的圆角应 ≤ 这个值 |
| `--island-gap` | `theme.gap` | `1` | 段间距由宿主排，插件不要自己加外边距 |
| `--island-font` | `theme.font` | Segoe UI Variable 栈 | 全站字体，不要另起字族 |

宿主 theme 里**没有**插件侧的语义色（成功/警告/危险）—— 那些是宿主界面用的。
插件自己的业务状态请用图标 + 文案表达，颜色只作辅助。

### 圆角阶梯（签名几何）

小岛胶囊 `999`（38px 高时实际被压到 19px）→ 中岛 `24` → 大岛 `28` → 工作台 `20` → 卡片 `12`。
插件在 Medium / Large 里画卡片用 `12`，用户换插件时不用重新适应几何语言。
宿主只提供几何预期，不提供卡片样式：卡片底 `#18181B`、描边 `1px #2E2E33`、
标签 `12px #A1A1AA`、数值 `22–28px / 700`。这些色值插件自己写死也可以（它们不在注入变量里），
但**不要再引入新的蓝**：强调色一律用 `var(--island-accent)`。

### 动效与可访问性

- 插件内部动画自己负责，但不要在宿主 hover 时自行缩放、位移或重排（见上）。
- 要尊重系统的「减少动态效果」：宿主已对 `prefers-reduced-motion: reduce` 关掉过渡与动画，
  插件里自己写 `@keyframes` 时请一并处理（改为静态状态，或把脉冲降到 ≤3Hz）。
- 岛内可点目标 ≥28px；纯装饰元素加 `aria-hidden="true"`；含信息的状态点必须同时给出可读文案
  （例如同时显示「余额偏低」，不能只靠一个红点）。
