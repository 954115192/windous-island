Activity Island · Plugin Showcase

首发插件

六个插件，每个都过同一组筛子：事件每天都发生、错过通知有真实代价、数据本机可得零配置。 其中五个带覆盖式通知——这是灵动岛存在的理由：你不需要盯着屏幕，岛替你盯，出事才说话。

可落地性：所有数据源在当前「可信插件」阶段即可实现（WMI / 文件系统 / 进程 / 已验证的公开接口）， 不依赖未来的权限模型；通知行为（三档、ttl、队列、同 key 覆盖）与宿主已实现的一致 （见 docs/plugin-contract.md §5）。

总览

按「日常痛感」排序。五个带通知，一个纯驻留倒计时；合起来覆盖岛的全部形态。

任务完成哨兵

task-done

构建 / 训练 / 复制跑完或失败立刻上岛。失败是红色，必须看——避免「早就失败了还在干等」。

通知 ×3驻留中岛

AI 余额哨兵

ds-balance

API 余额随用随扣，用挂了才知道没钱。低于阈值琥珀提醒，令牌失效红色。工作台同款接口。

通知 ×3驻留中岛

电量哨兵

battery-guard

没电永远在最要命的瞬间。低电量分级提醒，充到 80% 提醒拔电源。WMI 零配置。

通知 ×3驻留中岛

下载雷达

dl-radar

浏览器「下载完成」只在浏览器里，你早切窗口了。下完岛直接说一声，卡住也会说。

通知 ×2按需出现中岛

系统脉搏

sys-pulse

风扇狂转、卡到打不开文件，不知道是谁干的。持续过载琥珀提醒，中岛列出 Top 3 进程。

通知 ×3驻留中岛

专注番茄

focus-flow

倒计时驻留小岛，余光可见；结束轻提醒。计时器不再多开一个窗口——窗口本身就是打断。

通知 ×2驻留中岛

01 · 任务完成哨兵

最普适的一个：任何「跑一会儿才完」的事都适用，不只开发。

task-done

构建、模型训练、大文件复制、npm install……你切去干别的，只能一遍遍切回来看完没完。 更糟的是失败：10 分钟前就退出了，你还在等它「跑完」。

通知语义（与宿主实现一致）

五个带通知的插件共用同一套规则，行为定义在 docs/plugin-contract.md §5。

alert levels

info可错过

完成、恢复、周期提醒。错过了没有损失，历史里能找到。

描边 #60A5FA · 默认 4s

warn该知道

余额偏低、下载卡住、持续过载、电量 20%。不处理会变糟。

描边 #F59E0B + 光晕 · 默认 6s

critical必须看

任务失败、令牌失效、电量 10%、磁盘临界。错过有真实代价。

描边 #EF4444 + 光晕 · 默认 9s，可到 60s
  • 覆盖显示：提醒占住整条 mini 条，ttl 到期自动回落驻留态；点击提醒的岛进入该插件的中岛。
  • 同 key 覆盖：同一条提醒更新（如电量又降了 5%）立即顶替当前显示并重新计时，不排队。
  • 队列上限 3：正在展开看中岛时提醒排队不插屏；回 mini 条后依次放出。
  • 颜色 + 文字双通道：红圈必须配「令牌失效」这样的字——不只靠颜色传达状态。
  • 不重复叫：同一档事件静默直到状态实质变化（电量再降 5 点、充值、插上电源）。

这五条是宿主仲裁器已实现的行为，设计不引入新机制——插件拿来就能写。

为什么是这六个

以及为什么刻意不做另外几个。

selection
  • 事件每天都发生：跑任务、花钱调 API、用电、下载、电脑变卡、想专注——不是月度场景，是每天的场景。
  • 错过通知有代价：失败白等十分钟、跑批断在半路、演示没电、磁盘写满——每个通知都对应一个具体的损失。
  • 数据本机可得：WMI、文件系统、进程表、本地时钟、一个已验证的公开接口。装上就能用，没有「先去申请个 API」的门槛。
  • 合起来覆盖岛的四种形态：常驻槽（余额 / 电量 / 脉搏）、按需出现（下载）、倒计时驻留（番茄）、覆盖式提醒（五个）。演示平台能力不用解释，装上就看得到。
  • 刻意不做 · 会议哨兵：Windows 日历数据源（Outlook / ics / 企业 IM）每一个都不可靠，做出来会「有时灵有时不灵」——比没有更糟。
  • 刻意不做 · 股价 / 汇率 / 天气：与工作流无关，看完就忘，占的是最贵的常驻槽。
  • 刻意不做 · 剪贴板监听：轮询剪贴板的隐私观感差，收益只覆盖开发者小众场景；不配「首发」。

与现有资产的关系

不重复造：能复用的数据和规格都指回仓库。

mapping
  • ds-balance — 工作台已有「DeepSeek 用量」面板与令牌存储（console-apps/workbench），插件复用同一接口；工作台答全景，岛上收提醒。对齐 design/docs/PRODUCT.md 的 P1。
  • focus-flow — 仓库已有完整交互规格（docs/plugin-specs/focus-flow.md：滚轮调时长、状态机、存储键），本页只定它的产品位置与通知文案。
  • sys-pulse — 工作台 KPI 面板的常驻 + 告警化：工作台是「打开才看」，插件是「主动说」。对齐 P2。
  • task-done / battery-guard / dl-radar — 全新，但只用宿主已实现的能力：background 脚本（process 能力）、island.alert 三档、setPresence、storage。
