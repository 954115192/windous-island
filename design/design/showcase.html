灵动岛

Windows 桌面信息岛：四个容器（小岛 / 中岛 / 大岛 / 右键工作台）由插件驱动内容； 支持长期占岛与临时消息突出；工作台全局单例，插件多实例并行。 本页是视觉与标志性能力的设计基线，token 与 DESIGN.md 一致。

Figma MCP：本会话未连接 Figma MCP（无 use_figma / create_new_file）。 无法直接写入 Figma 画布。接入后可按本页 token 与容器规格建 Variables + 组件。 交付物：项目内 DESIGN.md、docs/PRODUCT.md、本展示页。
