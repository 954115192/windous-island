插件

这里是插件安装与运行管理的唯一入口：安装、启用、禁用、排序、参数、日志、重载和卸载。改开发目录里的文件会自动同步并热重载。

自己做一个插件

插件就是普通网页：plugin.json 清单 + dist/ 里的 HTML / JS / CSS，装好后由宿主在岛上直接渲染。「导出」把插件打成 .islandplugin 包，别人用「导入插件包」直接安装。「下载 Skill 包」导出插件生成规范（SKILL.md），给 Claude Code 等本地 AI 装上后就能按规范帮你写插件；工作台的规范在「工作台」页下载，两者不通用。

工作台

右键小岛打开的就是工作台。可以装多个，同时只有一个在用。
